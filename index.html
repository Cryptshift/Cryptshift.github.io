03 — Projects

Things I've built

Canvas Copilot

A local, read-only agent that watches UC San Diego's Canvas and my course syllabi so no deadline slips by. UCSD doesn't let students create API tokens, so it combines the Canvas calendar feed, each course's announcement feed, and a Playwright harvester that reads syllabi, including course sites outside Canvas.

Python Playwright SQLite iCal / Atom

Voxtral Reader

Reads scientific papers aloud with Mistral's Voxtral text-to-speech model, running locally on Apple Silicon. It extracts a PDF's text, cleans it up for listening, and plays it back in a small web app. Nothing leaves the machine.

Python FastAPI MLX Text-to-speech

Realtime Guitar Tutor

A browser app that listens to a guitar through the microphone, detects pitch in real time, and scores each note against a song for pitch and timing. It shows beginner tabs as you play, has a step-by-step mode that waits for the right note, and includes a tuner.

JavaScript Web Audio API Pitch detection Vite

LetMeSleep

An iPhone app that listens for noise, measures decibel levels, and has a Discord bot message a loud roommate when they cross a threshold, telling them exactly how many dB they're producing. Useful for roommates, neighbors, etc.

Swift SwiftUI AVFoundation Discord API
