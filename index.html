03 — Projects

Things I've built

Medical Data Entry Automation

End-to-end pipeline that eliminates manual "print and retype" workflows between Electronic Medical Records systems. Extracts structured fields from PDF exports, normalizes and maps them via a declarative DSL, runs probabilistic patient matching, and writes to the target EMR via API or RPA. Includes a human-in-the-loop review queue for low-confidence fields and a full audit trail exportable to CSV or SIEM. Handles PHI — HIPAA compliant with per-tenant encryption and redacted logs.
